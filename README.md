# Sistema_Biblioteca

Para ejecutar los scripts del sistema de biblioteca, se necesita instalar la librera Rich 
de python además de todos los archivos del proyecto, incluyendo los archivos json los cuales
contienen archivos predeterminados escenciales para que el proyecto funciones.

Todos los archivos deben estar en la misma carpeta, y se debe ejecutar en el main.py del 
proyecto.

Se recomienda probarlo desde la terminal, buscando la carpeta en la que esta el proyecto y
ejecutando el main.py

/-- ¿Cómo funciona nuestro proyecto?--/

Nuestro proyecto es una aplicacion de consola, donde se gestiona una biblioteca.
Es capaz de manejar prestamos, libros y usuarios.

Se navega a travez de distintos menus con comandos dentro de la terminal de consola.
